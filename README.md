# RewardsPro marketing history

Commercial outreach, install targets and posting quotas are retired.
`npm run run-wave`, including `--force`, and `npm run schedule` report retirement
without fetching metrics, generating media, changing records or posting.
`npm run status` reads existing local history without target comparisons.

Pure understanding is sufficient; no revenue, learning or output is required.
The [former campaign playbooks](docs/history/retired-commercial-direction-2026-09-23/agents__MARKETING-AGENT.md.txt) and source
remain as historical context. Provider helpers are not standing permission to
post, contact anyone or purchase media generation. Existing records are preserved.

No GitHub Actions schedule is tracked here. The former documentation proposed
a machine cron; publishing this source does not update a separate machine checkout.
